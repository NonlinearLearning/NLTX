# Terraria 网络领域术语

本词汇表描述线上 Terraria 消息与权威游戏会话的关系。状态为本轮设计提案；不改变已有 World Storage 词汇表。

## 协议身份

**协议配置（Protocol Profile）**：一组匹配同一对端协议的消息格式、模块身份和稳定布局事实。
_避免_：用编译器版本或源码目录名称代替对端协议版本。

**消息格式（Packet Format）**：某协议配置中，一个消息 ID 在指定传输方向上的值结构和线上表示。
_避免_：仅凭消息 ID 确定格式。

**消息（Packet Message）**：一次收到或准备发出的消息格式实例及其传输身份。
_避免_：把消息当作已经获准执行的游戏命令。

**模块消息（Module Message）**：承载在 NetModules 消息中的子消息，由协议配置确定模块编号及子动作身份。
_避免_：把全部 NetModules 视为同一种权限。

## 身份与会话

**网络会话（Network Session）**：一个对端连接所参与的协议交互、准入阶段及身份绑定。
_避免_：游戏会话、玩家实体。

**连接代次（Connection Generation）**：同一逻辑连接的一次独立建立，旧代次的消息和结果不属于新代次。
_避免_：认为相同地址或相同玩家槽位代表同一次连接。

**游戏会话（Game Session）**：一名参与者加入某个权威世界后获得的参与身份与资格。
_避免_：Socket、网络缓冲。

**玩家槽位（Player Slot）**：该 Terraria 协议配置中用于引用玩家的线上编号，由权威端分配。
_避免_：永久用户 ID、客户端声明的权威身份。

**连接身份绑定（Sender Binding）**：权威端认可的网络会话、玩家槽位与游戏参与者之间的关联。
_避免_：直接信任包体里的 Player、Owner 或 Author 字段。

## 权威处理与分发

**消息准入（Packet Admission）**：根据协议配置、方向、会话阶段及消息许可决定消息能否进入应用处理。
_避免_：编解码成功即获准执行。

**权威提交（Authoritative Commit）**：负责该游戏领域的 owner 校验并接受一次状态变化。
_避免_：网关直接写 ECS、发送入队即业务成功。

**权威转发（Authoritative Relay）**：依据权威处理结果向选定参与者发出消息。
_避免_：原始客户端帧自动广播。

**区域订阅（Section Interest）**：游戏参与者被允许接收的世界区段及其同步资格。
_避免_：仅由网关根据距离自行决定的游戏可见性。
