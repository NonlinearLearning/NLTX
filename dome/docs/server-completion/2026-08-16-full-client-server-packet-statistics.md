# 完整客户端/服务器会话数据包统计

日期：2026-08-16

## 统计口径

- 原始证据：[trace.jsonl](../../Build/diagnostics/full-client-server-20260816/trace.jsonl)。
- 自动汇总：[summary.json](../../Build/diagnostics/full-client-server-20260816/summary.json) 和
  [summary.md](../../Build/diagnostics/full-client-server-20260816/summary.md)。
- 仅统计成功的完整客户端/服务器会话，即 `connectionId=2` 的 `frame` 事件。
- `C2S` 表示客户端到服务器，`S2C` 表示服务器到客户端。
- 每个完整帧按其第一个载荷字节 `messageId` 归类；帧长度包含 2 字节小端长度前缀。
- 不计入无数据帧的预检连接 `connectionId=1`，也不计入全部 7 条非帧事件：
  2 条 `connect`、1 条 `listen`、1 条 `eof` 和 3 条 `socket_error`。其中后 4 条为
  终止事件。
