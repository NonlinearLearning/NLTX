### Family boundary

- Movement families separate gravity, liquid, flight, tile collision, and bounded counters.
- Target families keep business Player/NPC handles separate from encoded target indexes and preserve retarget/invalidation ordering.
- Boss, invasion, and event state belongs to `WorldProgressionState` or `WorldEventResourceState`, never an NPC-local copy.
- Worm/segment state owns parent/child links, shared-life, and tombstone transitions; town state owns home/service business only.
- Ranged/child-spawn and loot/status families model projectile/minion intent, Buff/DoT, hit immunity, and exactly-once death effects as separate typed owners.

## 5. Component boundaries and exclusions

| Owner | Allowed state | Must not own |
| --- | --- | --- |
| `NpcDefinition` | type, classification, difficulty, capability, static limits | per-instance AI counters, wire fields |
| `NpcLifecycleComponent` | active, timeLeft, death/despawn/replacement | net cadence, packet revision |

| `NpcHomeComponent` | home coordinates, timeout, door/home policy | UI name distance, wire message |
| `NpcBehaviorFamilyState` | typed family state, bounded counters | raw `float[] ai`, unbounded cache |
| `NpcBuffStateComponent` | type/time/immune state, bounded capacity | client buff display, packet payload |
| `NpcCombatComponent` | life/damage/defense/immunity/hit markers | hit sound/visual effect |
| `WorldProgressionState` | boss/event/invasion flags and queries | NPC-local global progression copy |
| `WorldEventResourceState` | tower shield/event resource | replication snapshot fields |
| `NpcLootStateComponent` | death source, once-only emission, drop intent | client loot animation |
| `NpcSpawnSlotPolicy` | bounded allocator protection and slot ownership | network slot encoding |
