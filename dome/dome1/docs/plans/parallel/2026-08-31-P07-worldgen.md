## 11. Pass-state and command contract

| Pass artifact | Read set | Write set | Random consumption | Output/commit | Retry, rollback, restart |
| --- | --- | --- | --- | --- | --- |
| `WorldGenerationRequest` | explicit seed, size, mode, evil input | immutable request envelope | none | input to pipeline | reject malformed input; restart from bootstrap |
| `WorldSeedComponent` + `WorldRuleSnapshotComponent` | request and rule registry | immutable seed/variant/rule snapshot | none | published before passes | snapshot is restart boundary; no partial mutation |
| `GenerationRandomState` | seed, pass id/version | pass stream cursor/checkpoint | scoped stream only; no global `Main.rand` owner | checkpoint stored with pass result | restore exact pass checkpoint; abandon commands on retry |
| `TileReadSnapshot` / `HousingScanSnapshot` | immutable world tiles, walls, liquid, bounds | local scan counters, visited set, failure reason | only when declared by pass | read-only input to queries | discard per-call scratch; restart from snapshot/cursor |
| `TileChangeCommand` / `LiquidChangeCommand` / `StructureCommand` | query result and expected section version | typed bounded mutation intent | no implicit draws | deterministic sequence into one commit queue | stale section or invalid command rejects whole batch |
| `WorldGenerationLifecycleSnapshot` | stage registry, cursor, failure | stage, active/loading, cursor, failure state | records checkpoint id, not stream owner | snapshot published after domain commit | resume at cursor; rollback uncommitted commands only |
| `WorldGenerationPipeline` | ordered stage registry and snapshots | pass result metadata only | declares per-pass budget | one y-major/sequence-ordered commit, then snapshot publication | stage retry is isolated; restart never reuses mutable static scratch |

Pyramid wall-frame evaluation is `completed_partial`: it consumes immutable read snapshots,
emits typed commands, validates section/version/sequence guards, and commits once. Its evidence
does not cover tunnel/features, full pass order, global RNG parity, liquid side effects, WLD
metadata, or protocol projection.

## 13. Server-field implementation addendum

基于 `D:\TRbackup\Version4物理删除了某些文件\Terraria\WorldGen.cs` 的字段/属性回查，
本轮将服务端字段进一步落到 Simulation owner：

- `WorldGenerationServerState`：规则快照、SavedOreTiers、Skyblock/tile presence、环境计数、
  tile-count 调度、感染总量、房屋扫描基础值、orb/altar/meteor/boss 进度、加载失败和清理状态。
- `WorldGenerationTerrainState`：surface/rock/underworld/ocean/beach 几何、spawn、dungeon、
  jungle、snow、desert 坐标与服务端生成门。
- `WorldGenerationProgressionState`：evil 选择、随机 evil 阶段、boss/meteor、orb/altar、
  town-NPC cadence、感染、冻结、hardmode、transform、generation cursor/stage。
- `WorldGenerationHousingState`：房屋边界、访问计数、候选坐标/score、家具需求、spawn gate、
  alternate-spot 递归门和 deterministic failure reason。
- `TileReadSnapshot`、`WorldGenerationPassState`、`WorldGenerationCommandBatch`：只读输入、
  pass checkpoint、随机游标和 tile/liquid/structure typed command 边界。

本 addendum 不关闭全局删除门。当前构建验证受工作区既有 Arch `ComponentType` 错误阻断。
