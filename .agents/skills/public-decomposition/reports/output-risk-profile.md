# Output Risk Profile

| 风险 | 失真表现 | 交付前检查 |
| --- | --- | --- |
| 成员遗漏 | 原模块成员没有归属或被默认丢弃 | 完成成员归属表，显式列出暂缓项 |
| 状态混淆 | 派生值、缓存、快照被当作权威状态 | 为每个写入者和失效条件标注所有权 |
| ECS 边界回流 | 巨型组件、查询写状态或继承重新承载行为 | 检查 Component/System/Query 职责和访问模式 |
| 依赖倒置 | UI、协议或第三方类型进入核心模块 | 检查 Adapter、Projection 和调用方向 |
| 行为回归 | 只编译通过，没有状态转换或调度验证 | 运行 focused verifier，记录命令和结果 |
| 过度拆分 | 文件增加但接口变浅、查询和不变量变复杂 | 说明 Depth、Leverage、Locality；必要时记录不拆分理由 |
| 证据越级 | 用 SS14 组件模式替代 Terraria/tModLoader 字段语义，或跳过源码回退顺序 | 为每个成员记录来源、版本、URL/行号和 `confirmed`/`partial`/`missing` 状态 |
| 盲目补全 | 四级来源不足仍凭名称或相似类型猜字段意义 | 关键字段为 `missing` 时停止，选择补证据 skill 并向调用者反问 |
