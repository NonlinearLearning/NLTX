# Non-communication simulation verification

Run the production-bound headless smoke against a WorldFile 319 sample:

```powershell
pwsh -NoProfile -File Test/NSSLC.Tools.Simulation.Verification/verify.ps1 `
  -WorldPath Build/diagnostics/WorldGenerationRoundTrip/12345-small-final/generated.wld `
  -SecondWorldPath Build/diagnostics/WorldGenerationRoundTrip/67890-medium-final/generated.wld `
  -FixtureHostBuild `
  -OutputDirectory Build/diagnostics/EntityOrganization/B8/simulation
```

The script builds only `NSSLC.Tools.Simulation.csproj` and its production references, then builds and runs the world-clock verifier. Pass `-FixtureHostBuild` to add `-p:FixtureHostBuild=true` to both builds and use the matching DLLs under `Build/bin/FixtureHost/<project>/Debug/net10.0/`; this keeps the verification graph separate from a regular server build. Clock assertions cover paused time, weather and event countdowns, rate-1 and fast-forward rates, rain and storm expiry, wind movement, moon phase rollover, and the final day/night ticks. It runs 600-tick cases with 0, 1, and 2 players, plus a production-kernel pause case. Scripted player scenarios check one-player movement, jump, and landing against the loaded world collision map, then route independent movement frames to two players. NPC scenarios check that the Demon Eye completes its hover/dive cycle and that the Guide changes position during its daytime patrol. World-item probes verify gravity, tile collision, lifetime advancement, expiry, partial pickup stack preservation, and full-inventory stack preservation. A runtime chest probe changes slot 0 through the world-container owner, saves it, and inspects the same chest and stack in a fresh process. A TileEntity probe runs for three ticks, removes its anchor after its first update, and verifies the cleanup pass unschedules it so the third tick does not revisit it. The script also triggers a wired pressure plate and actuator, then verifies the registered plate anchor and actuated tile survive save/reload. It generates deterministic 3600-tick inputs for natural NPC spawn, ordinary projectile hit/tile collision, combat/drop/pickup, and contact death/respawn, and checks that a liquid mutation reaches the world owner and its sealed probe survives save/reload. The projectile component verifier separately checks coordinator-owned lifetime expiration and slot release without a world-collision dependency. The liquid probe adds a synthetic source inside a sealed basin to the in-memory test session. The script rejects unsupported WorldFile versions, cancels during loading, checks that a locked-save failure preserves the previous file, and exercises repeated world switches when `-SecondWorldPath` is supplied. Reports and generated input scripts are written under the supplied output directory or `Build/diagnostics/NonCommunicationSimulationAudit/verification-run/` by default.

The save/reload assertion compares the sealed probe's tile state and saved world time. The full-map liquid checksums in `summary.json` are diagnostics taken before and after load recovery; recovery runs liquid settling and `WorldGen.WaterCheck` because WorldFile does not persist the liquid work queue. Those whole-map checksums can differ even when the saved probe state is preserved.
