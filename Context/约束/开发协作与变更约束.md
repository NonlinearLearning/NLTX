# 开发协作与变更约束

## 作用域与上下文

- 根级 AGENTS.md 覆盖整个目录树。更深层 AGENTS.md 可以补充局部要求，但不能削弱全局构建和安全要求。
- 开始工作先读 [progress.md](../progress.md)，任务需要时再读取活动上下文和计划。

## 变更边界

- 改动限定于用户请求，保留已有的无关修改。
- 迁移时不重写无关架构历史。
- 不对大范围路径执行破坏性清理；仅清理明确识别、由当前任务创建的临时文件。

## 导航维护

- AGENTS.md 以主题、读取条件和文档链接为主要内容，只保留必要的作用域与读取说明。
- 具体规则、命令、参数、例外和示例维护在对应主题文档中，入口不复述正文或规则摘要。
- 移动正文时逐条核对承接位置，保留适用范围和要求强度，并检查链接及旧锚点。
