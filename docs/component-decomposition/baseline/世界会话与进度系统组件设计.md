# 世界会话与进度系统组件设计

本文件依据《[Version4 世界会话与进度系统代码盘点及组件拆分报告](Version4世界会话与进度系统代码盘点及组件拆分报告.md)》
的成员归属表和组件边界，只定义组件字段、支持值对象字段和派生属性。它不是实现、迁移、
存档协议、System、Query、Command、Adapter、Projection 或测试设计。

建议命名空间为 `Terraria.WorldSession.Components`。普通字段均为组件拥有的状态；
表达式体属性只能从同一组件字段重复计算，不能成为另一份持久化或网络权威值。

- **权威**：世界加载、生成或运行期间的唯一状态来源。
- **运行期权威**：在会话中唯一，但不应误作长期进度旗标。
- **可重建**：运行期平滑值或缓存；不能作为存档真值。
- **派生**：只读属性，不单独写入。

以下五个组件附着于同一世界会话根，不附着于 `Player`、`NPC` 或 `Projectile` 实例。
`WorldPersistenceIdentity` 与 `SessionPhaseState` 是 `WorldDescriptorState` 使用的值对象，
不是第六、第七个世界根组件。`WorldId`、持久化 `UniqueId`、网络实体 ID 和实体槽位 ID 始终是不同概念。

```csharp
public sealed class WorldSessionRoot
{
  public WorldDescriptorState Descriptor = new();
  public WorldRulesState Rules = new();
  public WorldTimeWeatherState TimeWeather = new();
  public WorldEventProgressState EventProgress = new();
  public WorldSpawnPressureState SpawnPressure = new();

  // 派生：根不复制子组件中的 phase 真值。
  public bool IsReady => Descriptor.Phase.IsReady;
}
```

## 1. `WorldDescriptorState`

世界身份、尺寸、空间边界、生成锚点和准备生命周期。它不拥有 Tile、液体、TileEntity
或实体数组。

```csharp
public sealed class WorldDescriptorState
{
  // 权威：持久化世界身份。网络 ID 和实体槽位不在此处。
  public WorldPersistenceIdentity PersistenceIdentity;

  // 权威：世界尺寸与像素边界。
  public int SizeX;
  public int SizeY;
  public double LeftWorld;
  public double RightWorld;
  public double TopWorld;
  public double BottomWorld;

  // 权威：生成后固定的地形和出生锚点。
  public double SurfaceLayer;
  public double RockLayer;
  public int SpawnTileX;
  public int SpawnTileY;
  public int DungeonTileX;
  public int DungeonTileY;

  // 权威：会话准备生命周期。
  public SessionPhaseState Phase;

  // 派生：不单独持久化。
  public int SectionCountX => SizeX / 200;
  public int SectionCountY => SizeY / 150;
  public bool HasSurface => SurfaceLayer > 50.0;
  public WorldBounds Bounds => new(LeftWorld, TopWorld, RightWorld, BottomWorld);
}

public struct WorldPersistenceIdentity
{
  public int WorldId;
  public Guid UniqueId;
  public string Name;
  public string SeedText;
  public ulong WorldGeneratorVersion;

  // 派生：只表达本地持久化命名选择，不能充当网络会话或实体身份。
  public bool UsesGuidMapFileName => WorldGeneratorVersion >= 777389080577UL;
}

public struct SessionPhaseState
{
  public WorldPreparationState Current;

  // 派生：不能独立写入，避免与 Current 出现双真值。
  public bool IsGeneratingOrLoading =>
    Current is WorldPreparationState.Loading or WorldPreparationState.Generating;
  public bool IsReady => Current == WorldPreparationState.Ready;
}

public enum WorldPreparationState : byte
{
  Uninitialized,
  Loading,
  Generating,
  Ready,
  Failed,
  Unloading
}

public readonly record struct WorldBounds(
  double Left,
  double Top,
  double Right,
  double Bottom);
```

## 2. `WorldRulesState`

难度、特殊种子、世界邪恶类型、感染扩散和生成后长期规则。时间、天气、当前入侵和实体
实例状态不属于本组件。

```csharp
public sealed class WorldRulesState
{
  // 权威：模式、难度和 Hardmode。
  public int GameMode;
  public float? DifficultyOverride;
  public bool HardMode;

  // 权威：世界创建时确定的特殊种子集合。
  public WorldSecretSeedFlags SecretSeeds;

  // 权威：世界邪恶类型；感染开关目前是 partial 证据字段。
  public WorldEvilType WorldEvil;
  public bool InfectionSpreadAllowed = true;

  // 权威：生成后的长期资源规则。
  public OreTierState SavedOreTiers;
  public bool ShadowOrbSmashed;
  public int ShadowOrbCount;
  public int AltarCount;

  // 派生：不单独持久化。
  public bool IsJourneyMode => GameMode == 3;
  public float EffectiveDifficulty => DifficultyOverride ?? GameMode switch
  {
    1 => GameDifficultyLevel.Expert,
    2 => GameDifficultyLevel.Master,
    _ => GameDifficultyLevel.Classic
  };
  public bool IsExpertMode => EffectiveDifficulty >= GameDifficultyLevel.Expert;
  public bool IsMasterMode => EffectiveDifficulty >= GameDifficultyLevel.Master;
}

[Flags]
public enum WorldSecretSeedFlags : ulong
{
  None = 0,
  Drunk = 1UL << 0,
  ForTheWorthy = 1UL << 1,
  TenthAnniversary = 1UL << 2,
  DontStarve = 1UL << 3,
  NotTheBees = 1UL << 4,
  Remix = 1UL << 5,
  NoTraps = 1UL << 6,
  Zenith = 1UL << 7,
  Skyblock = 1UL << 8,
  Vampire = 1UL << 9,
  Infected = 1UL << 10,
  TeamBasedSpawns = 1UL << 11,
  DualDungeons = 1UL << 12,
  GetGoodWorld = 1UL << 13
}

public enum WorldEvilType : byte
{
  Corruption,
  Crimson
}

public struct OreTierState
{
  public int Copper;
  public int Iron;
  public int Silver;
  public int Gold;
  public int Cobalt;
  public int Mythril;
  public int Adamantite;
}

public static class GameDifficultyLevel
{
  public const float Journey = 0.5f;
  public const float Classic = 1f;
  public const float Expert = 2f;
  public const float Master = 3f;
  public const float Legendary = 4f;
}
```

## 3. `WorldTimeWeatherState`

世界时钟、天气和与昼夜生命周期一致的事件时钟。表现 alpha、云/雨渲染对象、音乐和
每帧标记不属于本组件。

```csharp
public sealed class WorldTimeWeatherState
{
  // 权威：世界时钟。
  public bool DayTime = true;
  public double Time;
  public int MoonPhase;

  // 权威：降雨状态。
  public bool Raining;
  public int RainTime;
  public float RainStrength;
  public int CoinRain;

  // WindTarget 和计数器为权威；WindCurrent 是可重建平滑值。
  public float WindTarget;
  public float WindCurrent;
  public int WindCounter;
  public int ExtremeWindCounter;

  // 权威：月事件和 Slime Rain 运行状态。
  public bool BloodMoon;
  public bool Eclipse;
  public bool PumpkinMoon;
  public bool SnowMoon;
  public bool SlimeRain;
  public double SlimeRainTime;
  public int SlimeRainKillCount;
  public int SlimeWarningTime;

  // 权威：昼夜快进和冷却。
  public bool FastForwardTimeToDawn;
  public bool FastForwardTimeToDusk;
  public int SundialCooldown;
  public int MoondialCooldown;

  // partial：事件实现与持久化路径尚未逐字段闭合。
  public CultistRitualState CultistRitual;
  public BirthdayPartyState BirthdayParty;
  public LanternNightState LanternNight;
  public SandstormState Sandstorm;

  // 派生：不单独持久化。
  public bool IsRainingForever => RainTime >= 5_184_000;
  public MoonPhaseValue CurrentMoonPhase => (MoonPhaseValue)MoonPhase;
  public float WindForVisuals => WindCurrent;
}

public enum MoonPhaseValue : byte
{
  Full,
  ThreeQuartersAtLeft,
  HalfAtLeft,
  QuarterAtLeft,
  Empty,
  QuarterAtRight,
  HalfAtRight,
  ThreeQuartersAtRight
}

public struct BirthdayPartyState
{
  public bool ManualParty;
  public bool GenuineParty;
  public int PartyDaysOnCooldown;

  // 运行期实体关系。旧存档的 int 槽位由存档适配器显式转换，不能当作持久化或网络身份。
  public List<NpcSlotReference> CelebratingNpcSlots = new();

  public bool IsUp => GenuineParty || ManualParty;
}

public readonly record struct NpcSlotReference(int Slot);

public struct LanternNightState
{
  public bool ManualLanterns;
  public bool GenuineLanterns;
  public bool NextNightIsLanternNight;
  public int LanternNightsOnCooldown;

  public bool IsUp => GenuineLanterns || ManualLanterns;
}

public struct SandstormState
{
  public bool Happening;
  public int TimeLeft;
  public float Severity;
  public float IntendedSeverity;
}

public struct CultistRitualState
{
  public int Delay;
  public int Recheck;

  public bool IsReadyToAttempt => Delay == 0 && Recheck == 0;
}
```

`CelebratingNpcSlots` 是短生命周期关系，必须在 NPC 槽位释放、会话清理或庆典结束时失效；
它不构成一个可跨会话引用的 NPC 身份。Version4 旧格式确实保存裸槽位整数，兼容读取时只能由
存档适配器转换，不能扩散为通用 ID。

## 4. `WorldEventProgressState`

Boss、入侵、NPC 解锁、Lunar、DD2 和待处理事件的世界级状态。它不拥有 NPC 的生命、
目标、位置、AI 或伤害归因账本。

```csharp
public sealed class WorldEventProgressState
{
  // 权威：长期 Boss 与入侵完成进度。
  public BossProgressFlags Bosses;
  public InvasionProgressFlags Invasions;

  // 权威：NPC 解救、出现解锁和世界解锁。
  public SavedNpcProgressFlags SavedNpcs;
  public NpcSpawnUnlockFlags UnlockedNpcSpawns;
  public NpcWorldUnlockFlags NpcWorldUnlocks;

  // 权威：四柱长期/运行态和月球事件。
  public LunarProgressState Lunar;

  // 运行期权威：当前入侵的世界运行状态。
  public InvasionRuntimeState Invasion;

  // partial：DD2 与待处理事件的逐字段迁移尚未闭合。
  public Dd2ProgressState Dd2;
  public PendingWorldEventsState PendingEvents;

  // 派生：不单独持久化。
  public bool AnyMechBossDowned =>
    Bosses.MechBoss1 || Bosses.MechBoss2 || Bosses.MechBoss3;
```

## 5. `WorldSpawnPressureState`

刷怪周期、城镇 NPC 刷新优先级和 Slime Rain 事件预算。活跃玩家数、区域资格、生命阈值
和“是否压制刷怪”均依赖即时实体/区域事实，不保存为本组件字段或属性。

```csharp
public sealed class WorldSpawnPressureState
{
  // 运行期权威：普通和城镇 NPC 刷新节奏。
  public int SpawnCheckCounter;
  public int NpcSpawnDelay;
  public int NpcSpawnPeriod;
  public int PrioritizedTownNpcType;

  // partial：Slime Rain 期间的事件预算与允许 NPC 类型集合。
  public float SlimeRainNpcSlots;
  public bool[] SlimeRainAllowedNpcTypes = Array.Empty<bool>();

  // 派生：只依赖本组件自身字段。
  public bool HasSpawnPeriod => NpcSpawnPeriod > 0;
  public bool IsTownNpcSpawnDue =>
    NpcSpawnPeriod > 0 && NpcSpawnDelay >= NpcSpawnPeriod;
}
```

## 6. `WorldStorageRoot` 交叉边界

以下组件属于主系统文档的“世界存储与身份”，不是 `WorldSessionRoot` 的子组件。这里列出字段
仅为固定会话与存储之间的类型边界；它们的变更不应携带天气、Boss 进度或会话 phase。

```csharp
public sealed class WorldStorageRoot
{
  public TileMapStore TileMap = new();
  public TileEntityStore TileEntities = new();
  public EntitySlotStore<PlayerState> Players = new();
  public EntitySlotStore<NpcState> Npcs = new();
  public EntitySlotStore<ProjectileState> Projectiles = new();
  public EntitySlotStore<ItemState> WorldItems = new();
  public ContainerStore Containers = new();
  public WorldSectionState Sections = new();
}

public sealed class TileMapStore
{
  public Tile[,] Tiles = new Tile[0, 0];
  public Liquid[] Liquids = Array.Empty<Liquid>();

  // 派生：不能与 WorldDescriptorState.SizeX/SizeY 双写。
  public int Width => Tiles.GetLength(0);
  public int Height => Tiles.GetLength(1);
}

public sealed class TileEntityStore
{
  public Dictionary<TileEntityId, TileEntityState> ById = new();
  public Dictionary<TileCoordinate, TileEntityId> ByAnchor = new();

  public int Count => ById.Count;
}

public sealed class EntitySlotStore<T>
  where T : class
{
  public T?[] Slots = Array.Empty<T?>();
  public BitArray ActiveSlots = new(0);

  public int Capacity => Slots.Length;
  public int ActiveCount => ActiveSlots.Cast<bool>().Count(active => active);
}

public sealed class ContainerStore
{
  public ChestState?[] Chests = Array.Empty<ChestState?>();
  public SignState?[] Signs = Array.Empty<SignState?>();

  public int ChestCapacity => Chests.Length;
  public int SignCapacity => Signs.Length;
}

public sealed class WorldSectionState
{
  public int Width;
  public int Height;
  public BitsByte[] Flags = Array.Empty<BitsByte>();

  public int Count => Flags.Length;
}

public readonly record struct TileCoordinate(int X, int Y);
public readonly record struct TileEntityId(int Value);
```

`Tile`、`Liquid`、`TileEntityState`、`PlayerState`、`NpcState`、`ProjectileState`、`ItemState`、
`ChestState`、`SignState` 和 `BitsByte` 在本文件中是既有存储类型的占位名称；本设计不重新定义它们的字段。
`EntitySlotStore<T>.ActiveCount` 是扫描结果，不能替代世界会话的进度或玩家人口资格。

## 7. 不属于组件字段的值

以下值已在报告中明确排除，不能为了便于调用而回流到上述五个组件：

- Tile、Wall、液体格子、TileEntity、容器和实体槽位；
- `Main.player`、玩家生命/魔力/库存/Buff、NPC 生命/AI/目标、投射物行为；
- `CurrentFrameFlags`、`cloudAlpha`、`invasionProgressAlpha`、
  `invasionProgressDisplayLeft` 与其他 UI/渲染表现值；
- 活跃玩家数、活跃城镇 NPC 数、区域资格、生命阈值和碰撞结果等即时计算；
- `Main.rand`、视觉时钟、随机服务和 `WorldFile` 写入临时变量。

## 8. 证据状态

`WorldDescriptorState`、`WorldRulesState`、`WorldTimeWeatherState` 的核心时钟/天气字段、
`WorldEventProgressState` 的 Boss/NPC/入侵/Lunar 字段，以及 `WorldSpawnPressureState` 的
刷怪周期字段均有 Version4 声明和主要持久化/使用路径证据。以下字段仍保持 `partial`：

- `InfectionSpreadAllowed`；
- `CultistRitual`、`BirthdayParty`、`LanternNight`、`Sandstorm`；
- `Dd2`、`PendingEvents`；
- `SlimeRainNpcSlots` 与 `SlimeRainAllowedNpcTypes`；
- `WindCurrent` 的完整重建、持久化和网络边界。

这些 `partial` 字段可以保留在设计中以标出候选所有权，但不能在实现中被当作字段级迁移已完成的证明。
