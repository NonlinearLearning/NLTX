# Version4 空间、移动、碰撞与液体组件字段设计

> 状态：字段与属性设计。基于
> [空间移动碰撞与液体系统组件拆分报告](空间移动碰撞与液体系统组件拆分报告.md)。
> 本文只定义 State、Buffer 与投影暂存状态的字段和只读派生属性；不定义方法、System、
> Query、Command、测试或执行顺序。

## 1. 范围

本设计覆盖报告中的 19 个状态组件：

1. `SpatialPoseState`
2. `KinematicState`
3. `CollisionShapeState`
4. `FacingState`
5. `MovementIntentState`
6. `CollisionPolicyState`
7. `ContactResultBuffer`
8. `LiquidContactState`
9. `MotionHistorySnapshot`
10. `TileLiquidState`
11. `LiquidWorkQueueState`
12. `LiquidSchedulerState`
13. `LiquidSettlingRecoveryState`
14. `LiquidReplicationDirtySet`
15. `DoorTraversalState`
16. `MountRuntimeState`
17. `PortalNetworkState`
18. `TeleportCooldownState`
19. `PylonRegistryState`

下列报告项不是组件，故不在本文定义字段：`SpatialSnapshot`、所有 System、Query、
Command、Catalog、网络 DTO 与表现 Projection。`SpatialSnapshot` 是查询输入；
`MountDefinitionCatalog` 是只读内容定义；`LiquidMergeTypeResolutionQuery` 是纯规则计算。

## 2. 字段约定

| 约定 | 含义 |
| --- | --- |
| `EntityId` | 当前世界会话内的实体引用；不是网络 ID、存档 ID 或内容 ID。 |
| `PersistentId` | 存档稳定标识，只在需要跨加载保存关系的状态中使用。 |
| `TileCoordinate` | 整数 Tile 坐标，不以像素或浮点世界坐标代替。 |
| `WorldPosition`、`WorldVelocity` | 世界空间浮点向量；前者使用实体左上角，后者按 Tick 表示。 |
| `SimulationTick` | 权威 Tick 序号。临时 Buffer 和 Snapshot 用它防止跨 Tick 复用。 |
| `ContentId` | 内容目录的稳定定义引用，不储存默认移动、坐骑或碰撞配置副本。 |
| `partial` | 字段边界由源码证明，但具体枚举值、完整写者或特殊行为仍受参考源码空体限制。 |

除 `TileLiquidState`、`LiquidWorkQueueState`、`LiquidSchedulerState`、
`LiquidSettlingRecoveryState`、`LiquidReplicationDirtySet` 与 `PylonRegistryState` 外，
组件均附着于实体。`ContactResultBuffer`、`LiquidContactState`、`MotionHistorySnapshot` 和
`LiquidReplicationDirtySet` 不写入世界存档。

## 3. Entity

### 3.1 `SpatialPoseState`

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Position` | `WorldPosition` | `WorldPosition.Zero` | 权威世界坐标，语义与 `Entity.position` 一致，为实体左上角。 |
| `Space` | `SpatialSpaceId` | `SpatialSpaceId.World` | 所属世界/子空间标识；不使用实体网络 ID 表示坐标系。 |
| `ParentEntityId` | `EntityId?` | `null` | 仅在实体相对另一个实体附着时使用的会话关系；独立实体为 `null`。 |
| `ParentOffset` | `WorldPosition` | `WorldPosition.Zero` | 相对父实体的局部偏移；仅当 `ParentEntityId` 非空时有效。 |
| `IsParentRelative` | `bool` | `false` | `ParentEntityId` 非空且姿态应按父实体解释时为 `true`。 |
| `IsWorldSpace` | `bool` 属性 | `Space == SpatialSpaceId.World && !IsParentRelative` | 只读派生属性，不保存第二份坐标状态。 |

### 3.2 `KinematicState`

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Velocity` | `WorldVelocity` | `WorldVelocity.Zero` | 当前权威线速度，对应 `Entity.velocity`。 |
| `Acceleration` | `WorldAcceleration` | `WorldAcceleration.Zero` | 本 Tick 已解析的加速度输入；不保存碰撞结果。 |
| `GravityScale` | `float` | `1f` | 重力强度倍率；零表示该实体不受常规重力影响。 |
| `GravityDirection` | `GravityDirection` | `GravityDirection.Down` | 权威重力方向；避免同时存储符号值和布尔反转值。 |
| `IsMovementLocked` | `bool` | `false` | 运动能力锁定标记；不表达输入是否到达。 |
| `IsStationary` | `bool` 属性 | `Velocity == WorldVelocity.Zero` | 只读派生属性。 |
| `IsGravityInverted` | `bool` 属性 | `GravityDirection == GravityDirection.Up` | 只读派生属性。 |

## 4. World Liquid

### 4.1 `TileLiquidState`

`TileLiquidState` 是 `TileMapStore` 中每个 Tile 的权威液体值，不创建为独立液体实体。

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Amount` | `byte` | `0` | 液体量，合法范围为 `0..255`。 |
| `Kind` | `LiquidKind` | `LiquidKind.Water` | 水、岩浆、蜂蜜或微光类型；当 `Amount == 0` 时不可作为独立液体事实读取。 |
| `IsChecking` | `bool` | `false` | 是否已进入液体工作队列，对应 Tile 的 `checkingLiquid` 标记。 |
| `ShouldSkip` | `bool` | `false` | 本轮是否跳过更新，对应 Tile 的 `skipLiquid` 标记。 |
| `LastChangedRevision` | `uint` | `0` | 此 Tile 液体内容最后一次已提交的世界 revision。 |
| `IsEmpty` | `bool` 属性 | `Amount == 0` | 只读派生属性。 |
| `IsFull` | `bool` 属性 | `Amount == byte.MaxValue` | 只读派生属性。 |
| `HasActiveWorkItem` | `bool` 属性 | `IsChecking && !IsEmpty` | 只读派生属性。 |

### 4.2 `LiquidWorkQueueState`

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ActiveItems` | `Queue<LiquidWorkItem>` | 空队列 | 已获工作预算、等待流动解析的活跃 Tile 项。 |
| `DeferredItems` | `Queue<TileCoordinate>` | 空队列 | 因活跃队列容量而延后入队的 Tile 坐标。 |
| `ScheduledCoordinates` | `HashSet<TileCoordinate>` | 空集合 | 去重集合；一个坐标在同一轮只允许一个工作项。 |
| `Capacity` | `int` | `25000` | 活跃队列最大容量，对应 `Liquid.maxLiquid` 的默认基线。 |
| `ActiveCount` | `int` 属性 | `ActiveItems.Count` | 只读派生属性。 |
| `DeferredCount` | `int` 属性 | `DeferredItems.Count` | 只读派生属性。 |
| `HasCapacity` | `bool` 属性 | `ActiveCount < Capacity` | 只读派生属性。 |

### 4.3 `LiquidSchedulerState`

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ConfiguredMaxActiveItems` | `int` | `25000` | 世界规则配置的活跃液体项上限。 |
| `CurrentMaxActiveItems` | `int` | `25000` | 当前 Tick 按玩家数和减载规则调整后的上限。 |
| `CyclesPerTick` | `int` | `10` | 常规液体更新轮次，对应 `Liquid.cycles`。 |
| `CurrentWorkBudget` | `int` | `0` | 本 Tick 可从队列取出的最大工作项数。 |
| `SkipCount` | `int` | `0` | 调度跳过计数，对应 `Liquid.skipCount`。 |
| `StuckCount` | `int` | `0` | 未沉降工作项计数，对应 `Liquid.stuckCount`。 |
| `StuckAmount` | `int` | `0` | 与 stuck 状态关联的累计液体量。 |
| `IsQuickFallEnabled` | `bool` | `false` | 快速下落模式。 |
| `IsQuickSettleEnabled` | `bool` | `false` | 快速沉降模式。 |
| `IsStuck` | `bool` | `false` | 当前调度是否判为阻塞。 |

### 4.4 `LiquidSettlingRecoveryState`

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `IsPanicMode` | `bool` | `false` | 是否进入强制液体沉降恢复模式，对应 `Liquid.panicMode`。 |
| `PanicCounter` | `int` | `0` | 队列压力持续计数，对应 `Liquid.panicCounter`。 |

### 4.5 `LiquidReplicationDirtySet`

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `PendingCoordinates` | `HashSet<TileCoordinate>` | 空集合 | 本 Tick 已提交、等待网络投影的液体坐标，对应 `_netChangeSet`。 |

| `PendingChangeCount` | `int` 属性 | `PendingCoordinates.Count` | 只读派生属性。 |
| `IsPublishing` | `bool` 属性 | `PublishingCoordinates.Count != 0` | 只读派生属性。 |

## 5. Door, Mount, And Teleportation

门和轨道的结构数据继续属于 `TileMapStore`；当前报告只把实体穿门协调状态列为组件，
未把门/轨道结构另立为 State 组件。

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `TrackedDoorAnchors` | `IReadOnlyList<TileCoordinate>` | 空列表 | 实体当前正穿越、等待关闭或需要重查的门锚点。 |
| `VelocityOnlyOpenTicksRemaining` | `int` | `0` | 允许按速度触发开门的剩余 Tick，对应 `_timeWeCanOpenDoorsUsingVelocityAlone`。 |

## 6. 组件内值对象字段

这些值对象只被以上组件的字段使用，不独立拥有 ECS 生命周期或权威写入入口。

### 6.1 `LiquidWorkItem`

| 字段或属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Coordinate` | `TileCoordinate` | `TileCoordinate.Zero` | 正在处理的液体 Tile。 |

## 7. 字段归属限制

| 字段组 | 唯一组件 | 不得重复保有 |
| --- | --- | --- |
| 世界位置、所属空间、父实体相对关系 | `SpatialPoseState` | `KinematicState`、门户、坐骑、网络 DTO |
| 速度、加速度、重力、运动锁定 | `KinematicState` | `MovementIntentState`、`ContactResultBuffer`、液体世界状态 |
| 宽高与碰撞偏移 | `CollisionShapeState` | `SpatialPoseState`、`TileLiquidState` |
| 玩家/AI 期望移动 | `MovementIntentState` | `KinematicState`、网络投影状态 |
| Tile 液体数量、类型和调度标记 | `TileLiquidState` | `LiquidContactState`、`LiquidReplicationDirtySet` |
| 活跃液体工作项 | `LiquidWorkQueueState` | `TileLiquidState`、`LiquidSchedulerState` |
| panic/沉降恢复进度 | `LiquidSettlingRecoveryState` | `LiquidSchedulerState`、网络投影状态 |
| 网络待发送液体坐标 | `LiquidReplicationDirtySet` | `TileLiquidState`、玩法组件 |
| 门的实体穿越窗口 | `DoorTraversalState` | `TileMapStore` 的门结构数据、`MovementIntentState` |
| 门户配对关系与传送冷却 | `PortalNetworkState`、`TeleportCooldownState` | `SpatialPoseState`、网络 DTO |

所有只读属性均由同一组件的字段或明确依赖的权威状态计算，不能缓存为第二份可写字段。

### 8.1 当前接入边界

`CollisionPolicyComponent`、`CollisionResultComponent`、`LiquidComponent`、
`MotionHistoryComponent`、`DoorTraversalComponent`、`LiquidSchedulerState`、
`LiquidSettlingRecoveryState`、`LiquidReplicationDirtySet`、`PortalNetworkState`、
`TeleportCooldownState` 和 `PylonRegistryState` 只保有字段和只读派生属性，尚未由所有玩家、
NPC、投射物或 TileEntity 的创建路径统一附加，也尚未接入读写它们的碰撞提交、液体接触、
自动开门或水晶传送 System。依当前用户要求，本实现不创建或维护
测试、console verifier 项目；验证范围仅限受影响生产项目的串行编译。本轮
`EntityEcs`、`Physics`、`Player`、`Teleportation` 和 `WorldStorage` 均已生成 `Build/bin` 产物；
前四者为 0 warning / 0 error，`WorldStorage` 为 15 个既有空存储字段 warning / 0 error，
不以新增测试为前提。

因此本次实现只完成状态边界，**没有**实现或宣称实现完整的 `TileSweepQuery`、台阶提交、
实体液体接触解析、液体流动/合并、自动门 Tile 事务、矿车轨道或水晶传送。后续 System
必须按拆分报告的 Tick 顺序读取这些组件，并通过既有的 `WorldGrid`、门或传送提交边界写入权威状态。
