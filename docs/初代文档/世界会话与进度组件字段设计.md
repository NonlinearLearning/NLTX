# 世界会话与进度组件字段设计

> 本文从《[世界会话与进度系统组件化拆分报告](世界会话与进度系统组件化拆分报告.md)》提取
> 可落地的字段与只读属性设计。它只定义 `WorldSession` 的状态形状，不定义 System、Query、
> Command、存档格式、网络包、迁移步骤或测试。
>
> 字段归属按 `public-decomposition` 的共同读写者、生命周期、持久化边界和语义内聚性划分。
> `confirmed` 代表报告已由 Version4 源码确认；`partial` 代表当前字段边界成立，但重建、完整写者
> 或事件细节尚未闭合。参考源码和外部 API 目录均为只读。

## 1. 会话实体与组件集

一个世界会话占用一个稳定的根实体。根实体以组合拥有五个状态组件：

```text
WorldSessionRoot (marker)
├─ WorldDescriptorState
├─ WorldRulesState
├─ WorldTimeWeatherState
├─ WorldEventProgressState
└─ WorldSpawnPressureState
```

| 类型 | 是否保存字段 | 说明 |
| --- | --- | --- |
| `WorldSessionRoot` | 否 | 仅标记“该实体是一个世界会话根”。不得重复保存世界 ID、名称、时间或进度；这些数据各自只存在于下列状态组件。 |
| `WorldDescriptorState` | 是 | 世界身份、布局、锚点和加载准备状态。 |
| `WorldRulesState` | 是 | 世界模式、难度、特殊种子、邪恶类型和长期规则门槛。 |
| `WorldTimeWeatherState` | 是 | 每 Tick 时钟、天气和依附于时钟的短期事件状态。 |
| `WorldEventProgressState` | 是 | Boss、入侵完成、NPC 救援/解锁、四柱和待处理世界事件。 |
| `WorldSpawnPressureState` | 是 | 刷怪周期、城镇刷新触发与事件刷怪预算。 |

所有“属性”均为只读派生值；它们不序列化、不网络复制为权威字段，也不允许被 Query 写入。

| `WorldPreparationState` | `WorldDescriptorState` | `Uninitialized`、`Loading`、`Generating`、`Ready`、`Failed`、`Unloading`。 |

## 3. `WorldDescriptorState`

**职责：** 保存同一世界的身份、固定空间描述、生成锚点和可用性阶段。Tile、Wall、Liquid、
区段位图、TileEntity、容器和实体槽位不在这里。

### 3.1 权威字段

| 字段 | 类型 | 状态 | 含义 |
| --- | --- | --- | --- |
| `WorldId` | `int` | partial | 旧格式世界整数 ID。它不是实体 ID、连接 ID 或网络实体 ID。 |
| `UniqueId` | `Guid` | confirmed | 跨保存/加载识别世界的稳定唯一标识。 |
| `Name` | `string` | confirmed | 世界显示名称。 |
| `SeedText` | `string` | confirmed | 用于重现生成规则的种子文本。 |
| `WorldGeneratorVersion` | `ulong` | confirmed | 生成器版本标识，用于加载/生成兼容性分支。 |
| `SizeX` | `int` | confirmed | 世界 Tile 宽度。 |
| `SizeY` | `int` | confirmed | 世界 Tile 高度。 |
| `Bounds` | `WorldBounds` | confirmed | 世界逻辑边界：`LeftWorld`、`TopWorld`、`RightWorld`、`BottomWorld`。 |
| `SurfaceLayer` | `double` | confirmed | 地表层顶部的 Tile Y 坐标。 |
| `RockLayer` | `double` | confirmed | 洞穴/岩层顶部的 Tile Y 坐标。 |
| `SpawnTileX` | `int` | confirmed | 无床玩家的默认出生 Tile X。 |
| `SpawnTileY` | `int` | confirmed | 无床玩家的默认出生 Tile Y。 |
| `DungeonTileX` | `int` | confirmed | 地牢锚点 Tile X。 |
| `DungeonTileY` | `int` | confirmed | 地牢锚点 Tile Y。 |
| `PreparationState` | `WorldPreparationState` | partial | 当前世界处于未初始化、加载、生成、可用、失败或卸载阶段。它是唯一的会话生命周期真值。 |

### 3.2 只读属性

| 属性 | 类型 | 计算 |
| --- | --- | --- |
| `IsReady` | `bool` | `PreparationState == WorldPreparationState.Ready`。 |
| `IsGeneratingOrLoading` | `bool` | `PreparationState` 为 `Loading` 或 `Generating`。不再保存第二个可变布尔字段。 |
| `SectionCountX` | `int` | 由 `SizeX` 和固定区段宽度派生。 |
| `SectionCountY` | `int` | 由 `SizeY` 和固定区段高度派生。 |
| `HasSurface` | `bool` | `SurfaceLayer` 是否为有效的已生成地表值。 |

### 3.3 明确不属于本组件的字段

- `Main.player`、`whoAmI` 和玩家/实体槽位属于 `WorldStorage` 与实体领域。
- Tile、Wall、液体格、区段加载位、箱子和 TileEntity 属于 `WorldStorage`。
- 客户端 `myPlayer`、`LocalPlayer` 和连接身份属于客户端/网络会话上下文。
- 世界包、存档 DTO、WorldFile 临时读取字段是 Adapter/Snapshot，不是会话描述字段。

## 4. `WorldRulesState`

**职责：** 保存世界级规则门槛。该组件不保存某个实体目前生命、AI、位置、库存或掉落实例。

### 4.1 权威字段

| 字段 | 类型 | 状态 | 含义 |
| --- | --- | --- | --- |
| `GameMode` | `int` 或具名 `WorldGameMode` 枚举 | confirmed | 基础世界模式。实施时应以具名枚举替换裸整数，但需保持旧值映射。 |
| `DifficultyOverride` | `float?` | confirmed | 覆盖基础模式难度的可选难度值。 |
| `HardMode` | `bool` | confirmed | 世界已进入 Hardmode；与 Wall of Flesh 进度语义关联，但不是 NPC 实例字段。 |
| `SecretSeeds` | `WorldSecretSeedFlags` | confirmed | 所有特殊种子开关的单一 Flags 值。 |
| `WorldEvil` | `WorldEvilType` | partial | 当前世界邪恶类型。 |
| `InfectionSpreadAllowed` | `bool` | partial | 感染扩散规则门控。 |
| `SavedOreTiers` | `OreTierState` | confirmed | 生成/保存的七种矿脉 tier。 |
| `ShadowOrbSmashed` | `bool` | confirmed | 暗影球是否至少被破坏过。 |
| `ShadowOrbCount` | `int` | confirmed | 已破坏暗影球累计数。 |
| `AltarCount` | `int` | confirmed | 世界中的祭坛计数。 |

### 4.2 只读属性

| 属性 | 类型 | 计算 |
| --- | --- | --- |
| `EffectiveDifficulty` | `float` | 优先使用 `DifficultyOverride`；否则从 `GameMode` 映射标准难度。 |
| `IsJourneyMode` | `bool` | `GameMode` 是否为 Journey。 |
| `IsExpertMode` | `bool` | `EffectiveDifficulty` 是否至少为 Expert 阈值。 |
| `IsMasterMode` | `bool` | `EffectiveDifficulty` 是否至少为 Master 阈值。 |
| `IsRemixWorld` | `bool` | `SecretSeeds` 是否包含 `Remix`。此属性供跨系统资格读取，不改变原始 Flags。 |

### 4.3 明确不属于本组件的字段

- 配方、掉落规则、`ItemID`、`NPCID`、`ProjectileID` 与默认样本属于只读 `ContentCatalog`。
- 当前生物群系扫描、局部 Tile 感染数据和生态传播队列属于世界生成/生态或 `WorldStorage`。
- Boss 已击败、NPC 救援和入侵完成属于 `WorldEventProgressState`；不要将这些进度复制为规则字段。

## 5. `WorldTimeWeatherState`

**职责：** 保存按 Tick 更新且被天气、NPC、投射物、生态和事件资格共同读取的时间环境状态。
同一时钟/天气事务中的字段放在一起；显示插值、粒子和云对象不进入该组件。

### 5.1 时钟字段

| 字段 | 类型 | 状态 | 含义 |
| --- | --- | --- | --- |
| `DayTime` | `bool` | confirmed | 原始昼夜相位。世界逻辑若需兼容 Remix，应结合 `WorldRulesState.IsRemixWorld` 进行 Query，而不是篡改此字段。 |
| `Time` | `double` | confirmed | 自最近昼/夜切换后的经过时间。 |
| `MoonPhase` | `byte` 或 `MoonPhaseValue` | confirmed | 当前月相。存储原始枚举值，保持与旧格式兼容。 |

| `FastForwardTimeToDusk` | `bool` | partial | 向黄昏快进的短期状态。 |
| `SundialCooldown` | `int` | partial | 日晷相关冷却。 |
| `MoondialCooldown` | `int` | partial | 月晷相关冷却。 |
| `CultistDelay` | `int` | partial | 与时钟相关的拜月教徒延迟。 |

### 6.11 明确不属于本组件的字段

- 某个 Boss/NPC 的生命、位置、AI、伤害贡献账本、目标和实体槽位属于实体、战斗或归因领域。
- `invasionProgressAlpha`、`invasionProgressDisplayLeft` 是表现投影；网络发送成功与否不得修改进度。
- Town NPC 房屋占用、`homeless` 和 NPC 到房屋关系属于 `TownHousingRegistry`/`WorldStorage`。
- 掉落表、NPC/物品默认定义和配方属于 `ContentCatalog`，不能以“进度字段”写入本组件。

## 7. `WorldSpawnPressureState`

**职责：** 保存刷怪调度需要的少数 Tick 计数和事件预算。活跃玩家数、区域危险度、住房可用性
和 Tile/生物群系资格均应在 Query 中从实体与 `WorldStorage` 即时计算，不能缓存成世界历史。

### 7.1 权威字段

| 字段 | 类型 | 状态 | 含义 |
| --- | --- | --- | --- |
| `NpcSpawnDelay` | `int` | confirmed | 下次 NPC 刷怪前的延迟/倒计时。 |
| `NpcSpawnPeriod` | `int` | confirmed | NPC 刷怪周期。 |
| `CheckForTownNpcSpawns` | `int` | confirmed | 城镇 NPC 刷新检查的 Tick 状态，映射旧 `Main.checkForSpawns`。 |
| `PrioritizedTownNpcType` | `int` | confirmed | 当前优先刷新 NPC 的内容类型 ID；它是定义 ID，不是 NPC 实体 ID。 |
| `EventSpawnBudget` | `float` | partial | 世界事件占用的刷怪预算。 |
| `SlimeRainNpcSlots` | `float` | partial | Slime Rain 的刷怪预算，映射旧 `slimeRainNPCSlots`；它不能包含 NPC 槽位数组。 |

### 7.2 只读属性

此组件当前不定义额外的持久化或缓存属性。以下值必须通过 Query 计算，不作为字段或属性固定在
`WorldSpawnPressureState` 上：

- 活跃玩家数量和是否存在符合条件的玩家；
- 活跃城镇 NPC 数量；
- 某区域、生物群系、时间、住房和事件条件下是否可刷怪；
- 某一实体槽位是否正被 Slime Rain、城镇刷新或事件预算占用；
- 是否应抑制刷怪。

### 7.3 明确不属于本组件的字段

- `bool[] SlimeRainNpcEnabled` 或任何按 NPC 槽位索引的数组；实体槽位归 `WorldStorage`。
- `ActivePlayerCount`、`ActiveTownNpcCount`、`HasEligiblePlayer`、`IsSpawnSuppressed` 等缓存；它们依赖
  活跃实体、区域和 Tile 状态，必须是纯 Query 结果。
- NPC 定义、刷怪权重、掉落、AI 状态与城镇住房关系；它们分别属于 `ContentCatalog`、NPC 领域和
  `TownHousingRegistry`。

## 8. 组件级排除清单

下表防止五个状态组件重新汇成巨型 `Main` 替代物。

| 数据类别 | 唯一归属 | 不得放入 `WorldSession` 的原因 |
| --- | --- | --- |
| Tile、Wall、液体、TileEntity、容器、世界区段 | `WorldStorage` | 它们按空间/槽位存储和变更，不与会话规则、时钟和进度同生命周期。 |
| Player、NPC、Projectile 实例字段 | 对应实体领域 | 生命、位置、库存、AI、寿命、归属和伤害均为实例状态。 |
| 实体槽位 ID、网络实体 ID、账户 ID、连接 ID | 实体/网络身份边界 | 不可与 `WorldId` 或 `UniqueId` 互换。 |
| `ContentSamples`、`ItemDropDatabase`、`Recipe`、`*ID` | `ContentCatalog` | 内容样本和定义只读，不能作为世界运行时或存档的第二权威源。 |
| 世界文件临时字段、二进制 Reader/Writer、网络包 | Persistence/Protocol Adapter | 它们是输入/输出边界，不能从投影反向写会话。 |
| 云、雨粒子、镜头、音乐、UI 进度透明度 | Presentation Projection | 它们可丢失或重建，不可影响权威玩法。 |
| 随机源、时钟服务、日志和消息发送器 | 显式端口/Adapter | 它们是副作用依赖，不是会话状态。 |

## 9. 与当前草案的对齐范围

`src/WorldSession/WorldSessionComponents.cs` 是未接线的早期草案。本设计采用其五个核心类型和已命名的
值对象，但字段归属以报告为准：

- `IsGeneratingOrLoading` 仅保留为 `WorldDescriptorState.PreparationState` 的派生属性，不能与阶段字段
  双写；
- `WindCurrent` 仅作为天气求解的派生输出，直到重建/保存规则补齐前不成为持久化真值；
- `SlimeRainNpcEnabled` 槽位数组不进入 `WorldSpawnPressureState`；
- 玩家数量、城镇 NPC 数量、资格和抑制状态不缓存为 `WorldSpawnPressureState` 属性；
- `downedMechBossAny`、事件是否开启等聚合值只以主字段派生，禁止保存重复旗标。

本文件是字段设计，不表示这些类型已经拆为同名 C# 文件、已接入 Tick、已完成存档/网络迁移，或已经
验证运行时行为。
