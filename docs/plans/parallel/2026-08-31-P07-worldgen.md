# P07 WorldGen Declaration and Pass-State Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 对 WorldGen 的字段、属性、常量、派生值和 scratch 做明确分类，补齐遗漏声明，
并将生成过程拆成可恢复、可审计的 pass-state 和 typed command 边界。

typed Tile/Liquid/Structure commands 和唯一 commit sequence 分离。legacy generator/reference、
日志、Color/background/render cache 只作为 host/client reference，不成为 Simulation owner。

**Tech Stack:** Documentation-only Markdown; no C# changes, no new functions, no tests/builds.

## 3. Count vocabulary reconciliation

P07 必须在工作稿中单列以下类别，防止 source inventory 与迁移分母混算：

| Category | Meaning | Can become Simulation field? |
| --- | --- | --- |
| method | 行为入口/消费者，不是字段 | only as reader/writer evidence |
| field | 静态/实例声明 | only after server-authority decision |
| property | getter/setter declaration | derived or mutable query, independently classified |
| property block | 旧报告统计单元 | not additive to `field` |
| constant | immutable rule/capacity | Definition only when real server consumer exists |
| derived value | from world/tile/rule state computed | query, no duplicate writable cache |
| scratch state | algorithm-local work area | per-call/per-pass workspace or excluded |
| host state | load/save/thread/logging orchestration | host-only |
| client-only state | background/color/UI/audio/render | excluded |

## 6. Component and pass boundaries

| Owner | Owns | Does not own |
| --- | --- | --- |
| `WorldGenerationRequest` | seed、size、mode、explicit generation inputs | UI text、file handle、packet field |
| `WorldSeedComponent` | immutable seed/variant selection | global mutable random stream |
| `WorldRuleSnapshotComponent` | secret seed and generation rules | background/color presentation |
| `WorldGenerationLifecycleSnapshot` | stage、active/loading、cursor、failure state | thread object/closure |
| `GenerationRandomState` | pass-scoped seed/version/stream/cursor | implicit `Main.rand` global owner |
| `TileReadSnapshot` | immutable input tile/wall/liquid/frame view | direct mutable legacy Tile reference |
| `TileChangeCommand` | tile/wall/frame mutation intent | network packet layout |
| `LiquidChangeCommand` | liquid value mutation intent | replication queue/cursor |
| `StructureCommand` | bounded structure placement/removal intent | UI or message request |
| `TileCountSnapshot` | deterministic counters/scan results | diagnostic-only uncoupled metrics |
| `HousingScanSnapshot` | bounds/visited/requirements/result | static global room stack |
| `WorldGenerationPipeline` | pass composition and source order | `_generator` as mutable state |

每个 pass 必须声明 read set、write set、random consumption、command output、commit order、
retry/rollback 和 restart checkpoint。不能把所有 pass state 放进一个大对象。

## 7. Classification rules for the omitted fields

- `Manifest` 只能停留在 compatibility/host metadata；如果未来需要 stage hash，使用 immutable
  manifest snapshot，不复制旧的可变 object reference。
- `mysticLogsEvent` 不因发生在服务器生成过程就自动成为 Simulation state；logging/audio
  是 excluded。
- `_generator` 不是 owner；它只描述旧 pipeline composition，目标是显式 stage registry。
- `BackgroundsCache`、`_coatingColors` 和 `drunkWorldGenText` 不进入 server world state。
- `TreeTops` 必须按“影响树生成结果的值”和“仅背景/渲染的值”拆分；不能以整个对象覆盖。
- `_SpawnThunderStorm_SafeSpots` 只有在 source consumer 改变权威生成/天气选择时才可 deferred；
  否则保持 excluded，不保存 visual safe-point cache。
