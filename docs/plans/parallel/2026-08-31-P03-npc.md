# P03 NPC Declaration and AI Family Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 补齐 NPC 未独立核对的字段/属性，并把每个 AI marker 归入可审计的 typed behavior
family，而不是用一个数组或 God Object 伪造覆盖。

**Architecture:** NPC definition、实体生命周期、target/home、Buff/DoT、world progression、
event resource 和 AI family state 分层。静态容量和派生世界查询不放到单个 NPC 实体；业务
target handle 与 wire target index 永远分开。

**Tech Stack:** Documentation-only Markdown; no C# changes, no new functions, no tests/builds.

## 4. AI family inventory contract

P03 必须从 source inventory 中为每个 `AI_###` marker 建立一行 family mapping。每行都要
填写以下字段，不能只填 marker 名称：

| AI marker | Behavior family | Typed state fields | Exact source readers | Exact source writers | Default | Phase | Random stream/state | Transition | Terminal condition | Owner | Persistence | Status | Deferred reason |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 每个发现的 `AI_###` | movement/target/boss/worm/town/event/loot 等 family | family-specific values | source methods/lines | source methods/lines | source default | spawn/tick/phase/death | seed/stream/checkpoint 或 none | typed command/commit | despawn/phase end/death | one behavior system | save/rebuild/transient | `partial/deferred` | 未闭合分支/顺序/consumer |

至少要检查以下 family 维度：

- 基础移动、重力、液体、飞行和 tile collision；
- target acquisition、retarget、target invalidation 和 Player handle；
- Boss phase、shield/resource、enrage 和 death transition；
- worm/segment shared life、parent/child、segment despawn；
- town NPC home/service/dialogue 的业务部分；
- invasion、event、spawn budget 和 world progression；
- projectile/minion/summon child spawn；
- loot、Buff/DoT、hit immunity 和 exactly-once death effects。

同一 `ai` 数值在不同 `aiStyle` 中有不同语义时，必须按 family 拆开，不能建立一个公共
`NpcBehaviorStateComponent<float[]>`。无法确定语义时写 `deferred`，并保留 source reader
和 writer，不能通过默认值猜测。

## 5. Component boundaries

| Owner | Allowed state | Must not own |
| --- | --- | --- |
| `NpcDefinition` | type、classification、difficulty、capability、static limits | per-instance AI counters、wire fields |
| `NpcLifecycleComponent` | active、timeLeft、death/despawn/replacement state | net cadence、packet revision |
| `NpcTargetComponent` | business Player/NPC target handle、retarget transition | encoded target index、packet slot |
| `NpcHomeComponent` | home coordinates、homeless timeout、door/home policy | UI name distance、wire message |
| `NpcBehaviorFamilyState` | typed AI family state and bounded counters | raw `float[] ai` as owner、unbounded shared cache |
| `NpcBuffStateComponent` | type/time/immune state with bounded capacity | client buff display and packet payload |
| `NpcCombatComponent` | life/damage/defense/immunity/hit markers | hit sound/visual effect |
| `WorldProgressionState` | boss/event/invasion flags and queries | NPC-local copy of global progression |
| `WorldEventResourceState` | tower shield/event resource | replication snapshot fields |
| `NpcLootStateComponent` | death source、once-only emission、drop intent | client loot animation |
| `NpcSpawnSlotPolicy` | bounded allocator protection and slot ownership | network slot encoding |
