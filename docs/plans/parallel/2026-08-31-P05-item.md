# P05 Item Declaration Closure Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 对 Item 的 140 个字段行和 8 个属性行逐一补齐声明级元数据、服务器 owner 和
行为缺口，保持 Definition、instance、equipment、use、economy 与 world-item 边界。

**Architecture:** Item 定义是 immutable source-derived value，Item instance 是可变数量/前缀/
变体/拥有关系，库存与世界物品是不同生命周期。持久化只输出 business value-only state；
Protocol/transport projection 不属于本任务。

**Tech Stack:** Documentation-only Markdown; no C# changes, no new functions, no tests/builds.

## 6. Component design and write ownership

| Owner | Allowed values | Write boundary |
| --- | --- | --- |
| `ItemDefinition` | type、size、stack cap、tool/combat/equipment/recovery capabilities | immutable registry/bootstrap |
| `ItemVariantDefinition` | variant rules and variant compatibility | definition registration |
| `ItemInstanceStateComponent` | item handle、type reference、quantity、prefix、variant、favorited | item instance command |
| `ItemUseStateComponent` | use phase、cooldown、consumption marker、validated target | item-use system/command |
| `ItemEquipmentDefinition` | slot/capability/stat contribution | definition owner |
| `EquipmentLoadoutComponent` | equipped item handles and functional slots | equip/loadout command |
| `ItemRecoveryDefinition` | life/mana/food/potion/flask effect values | definition; effect system reads |
| `ItemPlacementDefinition` | Tile/Wall/style/footprint/tool placement rules | placement validation/query |
| `WorldItemComponent` | position、active、owner reservation、pickup delay、revision | world-item spawn/pickup/merge commit |
| `ItemEconomyDefinition` | value/currency/shop eligibility | economy/catalog domain |
| `InventoryTransferPolicy` | stack compatibility、overflow、selected slot and transfer intent | inventory command; no direct foreign writes |
| `ItemPersistenceMapper` | value-only business representation | save/load adapter; no packet projection |

采用以下链条，末端只允许 business persistence：

```text
Definition -> Component -> System -> Snapshot -> business persistence
```

## 7. Required behavior and edge matrix

- [ ] `ItemID.Sets` 每一张真正被 server consumer 使用的表独立记录；无 consumer 的表保持

- [ ] tooltip、color、glow、sound、UI、Bestiary、animation、appearance-only rows 的

- [ ] 任何持久化映射都必须经过 value-only state；不得引用旧对象、线程、闭包或 Protocol layout。
