# Pelican Bicycle SVG Animation Design

## Goal

创建一个打开即可播放的单文件 HTML，用内嵌 SVG 绘制一幅带有海洋、道路、碎石人行道、像素云和方块落日的 2D 场景；主体是白色鹈鹕骑着红色老式自行车，持续蹬车前进。

## Scope and acceptance criteria

页面必须满足以下可见要求：

- 白色鹈鹕位于画面主体，双翅展开并搭在黑色车把上。
- 鹈鹕戴红色圆帽，脖子上围着卡通风格的红色围巾。
- 鹈鹕双脚连接在脚蹬/曲柄上，并以持续循环的动作蹬车。
- 自行车使用红色老旧车架、黑色车把和蓝色轮胎；车轮与脚蹬都持续运动。
- 背景上方是蓝色天空，包含大小不一的像素风格云朵与方块形落日。
- 画面中部有海洋，海洋与道路相连，形成通往地平线和前景的透视关系。
- 前景是带碎石质感的人行道，并明确画出自行车道标线。
- 文件不依赖网络资源；打开后自动播放，并提供点击暂停/继续。

不包含后端、资源下载、框架、构建步骤或自动化测试。

## Options considered

1. **纯 SVG SMIL 动画**：结构直观，但不同浏览器对 SMIL 的行为和调试体验不够一致。
2. **Canvas 绘制**：适合粒子和大量对象，但不利于保持鹈鹕、车架与场景图层的可读性，也不便于逐项调整造型。
3. **内嵌 SVG + CSS keyframes + 极少量 JavaScript（选定）**：所有形状都能作为可读的 SVG 元素检查和修改，CSS 负责稳定的循环动画，JavaScript 只负责暂停状态和无障碍提示，最符合“SVG 绘制”和单文件交付的要求。

## Architecture

HTML 只包含一个页面根节点和一个 `svg`。SVG 使用固定的 `viewBox="0 0 1200 720"`，通过 `preserveAspectRatio="xMidYMid slice"` 适应窗口尺寸。图层按以下顺序组织：

1. 天空渐变、星点/空气层、方块落日、像素云。
2. 海洋、远岸、道路透视面和自行车道标线。
3. 碎石人行道与前景石子。
4. 自行车后轮、前轮、老式车架、挡泥板、车座、车把和脚蹬。
5. 鹈鹕身体、头部、嘴、眼睛、圆帽、围巾、双腿和搭在车把上的双翅。
6. 前景高光、速度线与说明性 UI 状态。

所有颜色、纹理和几何形状都内嵌在 HTML 中。碎石使用可重复的 SVG pattern；云朵由方块矩形组成；太阳使用阶梯状方块轮廓。动画使用语义化 class：`wheel-spin`、`pedal-spin`、`ride-bob`、`wing-float`、`scarf-wave` 和 `cloud-drift`。点击 SVG 根节点切换 `is-paused` class，并更新隐藏状态文本和可见按钮提示。

## Animation behavior

- 前后车轮以相同方向持续旋转，轮毂与辐条保持可见。
- 脚蹬曲柄连续旋转；左右脚分别绑定到相反相位的短幅上下运动，始终保持在脚蹬附近。
- 自行车和鹈鹕整体做轻微上下起伏，制造骑行节奏，但不破坏双脚与脚蹬的连接。
- 双翅保持展开、翼根贴近车把，羽毛边缘只做小幅浮动，避免看起来像飞行。
- 围巾尾端和几朵云做低幅循环移动，增加风感和景深。
- `prefers-reduced-motion: reduce` 下停止循环动画，仍保留静态完整画面；用户点击暂停/继续时状态文本同步更新。

## Visual composition

- 天空从饱和蓝过渡到地平线的暖色；落日用橙黄方块放在海洋上方。
- 海洋位于画面中部，以多条水平波纹和明暗蓝色块表示；道路从远处窄口逐渐展开到前景，连接海洋与自行车道。
- 人行道采用暖灰色碎石图案，中心使用白色虚线和蓝色自行车道标识。
- 主体使用高对比轮廓：鹈鹕为暖白色配深蓝灰描边，自行车车架为旧砖红色，轮胎为蓝色，车把、车座和链条为接近黑色。
- 画面边缘保留留白与速度线，让主体在不遮挡海洋和道路关系的前提下成为视觉焦点。

## Verification boundary

按照用户要求，不创建或运行自动化测试。实现完成后只检查：文件存在、HTML 结构闭合、关键 SVG/动画标识存在，并在本地浏览器中打开确认静态构图、自动循环、暂停/继续与减少动态效果规则。验证结果记录在最终回复中，不把人工检查描述成测试通过。
